## Methods

These sketches describe this repository's implementations. Priorities use the
maximum-priority convention. `Attr(P, R, X)` is P's attractor to X inside R;
`Through(P, R, S, X)` reaches X while staying in safe set S, treating opponent
edges out of S as escapes. All CLI runs retain certificate verification.

### Attractor-decomposition lifting and host choices

Reference: [symmetric attractor-decomposition lifting](https://arxiv.org/abs/2010.08288),
[Raghavan's thesis](https://thejaswiniraghavan.github.io/PhD_Thesis.pdf), Algorithm 5 / Proposition 7.2.1;
[ad_lift.c](src/ad_lift.c), [ad_lift_solve.c](src/ad_lift_solve.c), [stree.c](src/stree.c).

```text
n = residual vertex count; t_full = floor(log2(n))
For each player P:
    d = least bound >= maximum residual priority with parity P
    H = (d - P)/2 + 1; K_full = min(H, t_full + 1)
    Choose the base ordered host T:
        default: U^K_full_(t_full,H)
        --tree-k=K: U^min(K,K_full)_(t_full,H)
        --kary=A: full A-ary tree with H node levels
        --tree-file: parse bitstring-vector leaves into an ordered prefix tree
    Refuse Strahler/A-ary hosts exceeding --max-host-leaves before allocation
    Flatten leafy_infinity(T) in depth-first order:
        regular eta, minus(eta), child block, child+, ..., TOP
    mu(v) = first position compatible with priority(v)
    Repeat, evaluating all vertices against the same mu:
        regular eta is valid if a P edge (all opponent edges) ends below after(eta)
        lazy ell is valid at v iff v is in
            Through(P, residual, {mu <= ell}, {mu < ell})
        TOP is always valid
        Move every invalid v to its next priority-compatible position
    Until every vertex is valid
    Dominion = {v: mu(v) < TOP}
    Materialize each occupied regular host node:
        A = fibre(eta) union fibre(minus(eta))
        For each occupied child c in host order:
            S_i = fibres in [c, after(c)); A_i = S_i union fibre(c+)
            recursively materialize c; prune empty host branches
Complete iff both dominions cover the residual; otherwise report Unresolved
```

`U^K_(t,H)` is the Strahler-universal host generated by `stree.c`, not the
occupied result tree. Default hosts are universal; restricted hosts can be
partial. A tree-file host has its own height and must fit each player's bound.
An empty residual needs no hosts and produces zero tree metrics.

```text
--adaptive-t (lifting only):
    For t = start_t, ..., t_full (start_t is clamped to t_full):
        For each P choose K = min(H_P, t+1, optional tree-k cap)
        Build/lift from bottom in U^K_(t,H_P); skip an unchanged host
        Remember the first t attaining each player's largest dominion seen
        Stop when both dominions cover the residual
        On a later host limit retain the previous certificates as partial
        (a limit before both players have run is an error)
--adaptive-t=incremental:
    Use the same schedule, but seed certified opponent wins at TOP
    Restart other labels from bottom, without assuming successive hosts embed
    Assert equality with cold adaptive DOT in this inventory generator
```

See [incremental search and non-nesting](docs/incremental-t.md) for the proof,
per-host comparisons, and why this does not project old labels into new hosts.
The wrapper discards all DOT on a host limit, including CLI partial output.

### Enhanced Zielonka

Reference: [Raghavan's thesis](https://thejaswiniraghavan.github.io/PhD_Thesis.pdf), Algorithm 7;
[zielonka.c](src/zielonka.c).

```text
Solve(R, d):
    Empty R: return empty regions and trees
    d = 0: return R won by Even, with one node whose top attractor is R
    P = parity(d); Q = opponent(P); remaining = R
    Q_tree = empty accumulator at bound d+1
    While remaining is nonempty:
        A = Attr(P, remaining, {v: priority(v) = d})
        recursive = Solve(remaining minus A, d-1)
        If recursive has no Q winners:
            Reuse its P witness (or create one); set its top attractor to A
            Return remaining won by P, R minus remaining won by Q,
                   the P witness and accumulated Q_tree
        S = recursive Q region; B = Attr(Q, remaining, S)
        Append (trap S, attractor B, recursive Q witness) to Q_tree
        remaining -= B
    Return R won by Q with Q_tree
```

This implementation accumulates opponent dominions in removal order and reuses
the terminating same-player witness. It does not reconstruct trees with a
second independent solver; its shape can differ from least-labelling lifting.

### Symmetric Zielonka with memory

Reference: [Raghavan's thesis](https://thejaswiniraghavan.github.io/PhD_Thesis.pdf), Algorithm 8;
[ad_sym.c](src/ad_sym.c), `solve`, `move`, `is_ad`.

Both symmetric methods share the recursion below. `core(P,a)` excludes a's
side; `Set(P,X,a)` increases labels in X to at least a's side. `Move` advances
only a T/S fibre outside its required attractor to the next child/sibling,
using priority to choose H/T/S there, or to the enclosing side if exhausted.
`is_ad` tests regular edges and lazy reach-through-safe attractors in the call's
subgame, and requires every label to lie in the specified core.

```text
Initialize both labellings at their root's priority-compatible H/T positions
Use implicit complete n-ary hosts, creating children only when visited
Move the higher root's unsupported T fibre past its empty top attractor
Solve(R, lower player P, node a, higher opponent node b):
    If is_ad(P,R,a): Set(Q,R,b); return R
    If is_ad(Q,R,b): Set(P,R,a); return empty
    For each child c of b while R is nonempty:
        A = Attr(P,R,{priority = level(a)})
        Move(P,a.T outside A)
        Set(Q,A intersect core(Q,c),c)
        U = R intersect core(Q,c)
        escaping = U intersect Attr(P,R,R minus U)
        Set(Q,escaping,c); U -= escaping        # close stale child to a total trap
        If U nonempty: U = Solve(U,Q,c,a)       # swap players and bounds
        B = Attr(Q,R,U); Move(Q,c.S outside B)
        Set(P,B intersect core(P,a),a); R -= B
        If is_ad(P,R,a): Set(Q,R,b); break      # Algorithm 8's memory stop
    Return updated R
Flatten visited host nodes, verify final labellings, materialize occupied trees
```

The labels persist across recursive calls. The entry condition allows the
higher player's **side**, and closing stale children is an added operation.
See [symmetric correspondence and corrections](docs/symmetric.md) for the
invariant, thesis errata, and justification; those details are maintained there.

### Symmetric attractor-decomposition lifting

Reference: [Raghavan's thesis](https://thejaswiniraghavan.github.io/PhD_Thesis.pdf), Algorithm 9 and §8.3;
[ad_sym.c](src/ad_sym.c), [ad_lift_solve.c](src/ad_lift_solve.c).

```text
Build the fixed pair of Strahler, A-ary, or tree-file hosts described above
Run the shared symmetric recursion, retaining labels in both supplied hosts
    Keep its two entry validity tests and the stale-child trap closure
    Exhaust supplied children; omit Algorithm 8's in-loop memory stop
Interpret returned R as a separator, not yet as two winning certificates
For each player, continue asymmetric short lifts from the resulting labelling
Verify and materialize the final non-TOP dominion, pruning empty branches
Return complete iff both certified dominions cover the residual
```

Universal hosts must yield complete results. Smaller fixed hosts can leave
Unresolved vertices. Adaptive hosts are rejected for Algorithm 9. Certification
continues existing labels; it does not reset to bottom.

### Strahler progress-measure lifting

Reference: [The Strahler Number of a Parity Game](https://arxiv.org/abs/2003.08627);
[pm_solve.c](src/pm_solve.c), [pm_lift.c](src/pm_lift.c), [strpm.c](src/strpm.c), adapted from Oink.

```text
Parameter search starts at (k,t) = (1,1)
t_max = floor(log2(n)); k_max = min(t_max+2, maximum counter depth+1)
Use Oink's min-heap with integer ratio max(k,t)/min(k,t), including its tie order
For each popped pair (or the CLI's fixed pair):
    Independently for Even and Odd on the entire residual:
        Counter priorities have the opponent's parity; k = min(k, depth+1)
        Initialize bottom compressed bitstrings (capacity k-1+t)
        Visit vertices in descending (priority, external ID) order
        Progress a successor measure by strpm_successor at an opponent priority
        At winner-owned v choose minimum progress; at opponent-owned v maximum
        Increase v only if its priority-truncated measure must increase
        Propagate changes through predecessors with Oink's dirty stack order
        Stop at the fixed point; non-TOP vertices are a certified dominion
    Stop search when the two non-TOP regions cover the residual
    Otherwise push unseen (k+1,t) before (k,t+1), within bounds
Deduplicate non-TOP measures and draw their ordered prefix trees
    Binary strings use the recursive paper order 0beta < empty < 1beta
    Leaves list vertices; raw .leaves retain first occurrence in ascending
    (priority, external ID) order, using e for an empty component
```

The integer ratio and stack schedule are deliberate compatibility choices.
Strahler measures retain untruncated tails; the verifier checks the truncated
condition on actual edges. The full-game search includes the extra root level.

### Succinct progress-measure lifting

Reference: [Succinct progress measures for solving parity games](https://arxiv.org/abs/1702.05051);
[pm_solve.c](src/pm_solve.c), [pm_lift.c](src/pm_lift.c), [sspm.c](src/sspm.c), adapted from Oink.

```text
For bits = 1, ..., ceil(log2(n)) (zero for zero/one-vertex games), or fixed bits:
    Run the same two independent full-residual lifting loops and dirty stack
    Store a bounded total bit budget across the counter components
    At opponent priorities use sspm_successor at the truncated priority index
    At winner priorities use sspm_truncate (unlike Strahler's retained tails)
    Stop at the first budget whose two non-TOP sets cover the residual
Verify edge progress and dominion closure; draw/dump distinct measures as above
```

The PM CLI also supports `--incremental` (unused by this inventory): remove
Even's non-TOP dominion and its attractor before running Odd on the remainder;
print each round separately. Succinct repeats a bit budget after progress.
Strahler uses Oink's smaller outer k bound, without the full-game extra root,
and can finish partial. Fixed parameters request one round.

### Shared shaving and priority compression

Reference: [Oink (TACAS 2018)](https://arxiv.org/abs/1801.03859), trivial dominions and priority compression;
[pg_preprocess.c](src/pg_preprocess.c), [pg_game.c](src/pg_game.c).

```text
Build a sorted map of distinct priorities; preserve order and parity
    Normally keep distinct levels, filling only the parity-required gaps
    With --compress merge consecutive distinct priorities of the same parity
Initialize active = all vertices; shaved[Even] = shaved[Odd] = empty
Repeat enabled rules in the order single, loops, wcwc until active stops shrinking:
    single: if all active priorities have parity P, remove all as P-winning
    loops: find self-loops whose priority parity P owns the vertex, or whose
           vertex has no other active successor (including losing-owner loops)
    wcwc: search from winner-owned roots in descending priority order;
          at bound d, find cyclic SCCs in owner-parity(d) vertices of priority <= d;
          retain SCCs whose actual maximum priority has that owner's parity
    For loops/wcwc, collect targets for both players, then for Even followed by Odd:
        B = Attr(P,active,targets[P]); shaved[P] += B; active -= B
    Count each removed vertex, including attracted vertices, only for its first rule
Apply the priority map to the game after shaving succeeds
Verify residual totality and both shaved regions' attractor/closure conditions
Run the selected backend on active; render shaved regions separately
```

The map is built from the full input, so shaving does not rebuild its levels.
Display uses original priorities by default; a compressed level maps back to
its largest original priority. Compression changes neither winners nor parity.
